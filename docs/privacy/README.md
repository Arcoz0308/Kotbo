# Gouvernance des données Kotbo

Ces documents décrivent le dispositif interne de conformité. Ils doivent être revus à chaque nouveau module, nouveau prestataire ou changement significatif de finalité.

- `processing-register.md` : registre synthétique des traitements.
- `legitimate-interests.md` : tests de mise en balance.
- `dpia-screening.md` : dépistage AIPD et mesures attendues.
- `rights-procedure.md` : procédure de traitement des demandes.

## Limite connue et hors chantier

La suppression lors du retrait d'une guilde, les cascades de données et l'automatisation complète des durées de conservation restent à traiter séparément. Aucune affirmation de ce dossier ne doit être utilisée comme preuve que ces mécanismes sont déjà opérationnels.

## Informations contractuelles à confirmer avant publication

- identité juridique complète et adresse postale de l'opérateur de Kotbo ;
- nom, pays d'hébergement et garanties de transfert de chaque hébergeur réellement utilisé ;
- configuration de production de Sentry et liste exacte des modules tiers activés ;
- mécanisme rendant le DPA opposable (contrat, bon de commande ou acceptation horodatée).
